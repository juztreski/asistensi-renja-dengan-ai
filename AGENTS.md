# AGENTS.md

## Project

- Flask app for assisting Bappeda Soppeng in reviewing OPD Renja documents and producing DOCX/XLSX worksheets.
- Entry point: `app.py`. Pipeline: `extract_renja.py` → `align_check.py` → `review_fields.py` → `generate_worksheet.py`; `llm_analyzer.py` is optional.
- No frontend build step and no database. UI uses Jinja templates and plain CSS/JS.
- User-facing UI and generated documents are in Indonesian; keep new labels and narratives in Indonesian.
- Full setup, routes, scoring, and deployment notes are in `README.md`.

## Verified commands

Use the repo venv; system Python does not have `openpyxl`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python app.py                    # http://127.0.0.1:5000
.venv/bin/python -m pytest -q              # full suite
.venv/bin/python -m pytest -q tests/test_core.py::test_analysis_finds_intentional_errors
.venv/bin/python scripts/build_sample_xlsx.py
.venv/bin/python -m gunicorn --workers 1 --threads 4 --timeout 180 --bind 127.0.0.1:8000 app:app
```

There is no lint, formatter, or typecheck configuration. `pytest` is the only configured verification.

## Non-obvious constraints

- `data/nomenklatur_kab_kota.json` is a **CONTOH/SEED** master, not the official longlist. The official master is not in this repo; never treat seed matches as authoritative.
- Sample Renja files intentionally contain errors. Do not “fix” them unless the task is explicitly to change fixtures.
- Tests assert exact sample outputs: 2 programs / 4 kegiatan / 10 subkegiatan, 17 findings (2 Kritis, 6 Sedang, 9 Saran), and a 100 score after all findings are marked `Dikoreksi`. Intentional rule changes require updating tests.
- `sample/renja_bappeda_contoh.xlsx` is generated by `scripts/build_sample_xlsx.py`, which duplicates fixture data also present in `sample/renja_bappeda_contoh.csv`. Update both and regenerate when changing the sample.
- `JobStore` is in-memory. Jobs and uploaded files disappear on restart; run a single Gunicorn worker. `.flask_secret` and `uploads/` are runtime-generated and gitignored.
- `tests/conftest.py` sets `UPLOAD_DIR`, a test secret, and unsets `GEMINI_API_KEY`/`GOOGLE_API_KEY` before importing `app`. Keep that env setup before any `app` import; tests must not call the network.
- Review form contract: fields are `status_<finding_id>` and `catatan_<finding_id>`. A non-empty `bulk` value overrides statuses and forces the “simpan” action.
- AI is optional and only runs when `GEMINI_API_KEY`/`GOOGLE_API_KEY` is set, the `google-genai` package is installed, and the form sends `use_llm=on`. Scanned PDFs have no OCR fallback.
- Worksheet tests verify document structure, not visual pagination. If changing identity/summary XLSX layout, inspect the output with LibreOffice (`soffice --headless --convert-to pdf`).
- The app has no built-in authentication or CSRF protection; do not expose it publicly without an SSO/reverse proxy or additional protection.
